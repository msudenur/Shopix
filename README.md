# Shopix
Java-based Object-Oriented Programming project developed by a team of 4 students.

## Gereksinimler

Kodun çalışması için sisteminizde aşağıdakilerin kurulu olması gerekir:

1. **Java Development Kit (JDK):**
   - En az Java 8
   - Tercihen Java 17 veya üzeri

2. **Java IDE**
   - Eclipse IDE önerilmektedir.

3. **SQLite JDBC Driver**
   - Projenin veritabanına bağlanabilmesi için
     `sqlite-jdbc.jar` dosyasının projenin Build Path / ClassPath kısmına eklenmiş olması gerekir.

## Projeyi Çalıştırma

1. Projeyi Eclipse IDE veya başka bir Java IDE ile açın.
2. Projedeki `src` klasörünün doğru şekilde tanımlandığından emin olun.
3. `Main.java` dosyasını bulun.
4. `Main.java` dosyasına sağ tıklayın.
5. `Run As > Java Application` seçeneğine tıklayın.
6. Program çalıştığında giriş ekranı açılacaktır.

## Kullanım Talimatları

### Kullanıcı İşlemleri

- Yeni kullanıcı sisteme kayıt olabilir.
- Kayıtlı kullanıcı kullanıcı adı ve şifresi ile giriş yapabilir.
- Kullanıcı ürünleri görüntüleyebilir.
- Ürünleri sepete ekleyebilir.
- Sepetteki ürünleri silebilir.
- Satın alma ve ödeme işlemlerini gerçekleştirebilir.

### Admin İşlemleri

- Admin kullanıcı sisteme giriş yapabilir.
- Admin panelinden ürün ekleyebilir.
- Ürün silebilir.
- Ürün bilgilerini güncelleyebilir.
- Stok durumunu kontrol edebilir.
